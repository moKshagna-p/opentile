§01The idea

Why does tiling feel rigid?

AeroSpace is great — tree-based tiling, vim keys, multi-monitor. But moving windows is keyboard-only and discrete. Every aerospace move left snaps to a grid slot. There's no flow, no muscle memory of just grabbing a window and putting it somewhere.

OpenTile fixes this. It reads raw trackpad data via Apple's private MultitouchSupport framework, detects a grab gesture, pops the window into floating mode, moves it pixel-smooth via the Accessibility API, then snaps it back into the tiling tree on release.

§04Technical details

Under the hood.

MultitouchSupport.frameworkA.1
Apple's private framework in /System/Library/PrivateFrameworks/. Exposes raw touch data globally — position (0.0–1.0 normalized), pressure, angle, contact state.

Key path: MTDeviceCreateDefault() → MTRegisterContactFrameCallback() → MTDeviceStart().

Bridged directly in Swift via a minimal C header — ~40 lines, no third-party dependency.
Accessibility API (AX)A.2
Public API for reading and setting window frames. AXUIElementCopyAttributeValue for AXPosition / AXSize.

Requires AXIsProcessTrusted() — the user grants Accessibility permission in System Settings.

Frame updates are instant — no animation, no delay. This is the 60fps path.
AeroSpace CLIA.3
Shell out to aerospace for tree operations. layout floating pops the window out of the tiling tree; layout tiling snaps it back in.

During drag, OpenTile bypasses AeroSpace entirely and moves the window via AX. AeroSpace only handles the before / after.
App structureA.4
Menu-bar daemon (no dock icon). NSStatusBar with a single status item.

Runs an MTDevice listener on its own callback thread.

Single executable — no background agent, no helper processes.

§06Known constraints

Eyes open.

RiskAssessment
🚫

No App Store

Private framework + Accessibility API = outside the sandbox. Distribute via Homebrew or signed .pkg.

⚠️

Private framework drift

MultitouchSupport can break on macOS updates. A maintenance tax, not a blocker — the ABI has been stable for 10+ years.

🔑

Accessibility permission

Requires AXIsProcessTrusted(). User must grant in System Settings → Privacy → Accessibility.

🤝

Gesture conflicts

System gestures (Launchpad, Mission Control) may collide. Pick a distinct finger count or intercept before the system recognizer.

🔒

SIP stays on

System Integrity Protection is untouched. MultitouchSupport is readable without disabling anything.

📐

Ponytail discipline

No speculative abstractions, no interfaces-with-one-impl, no config for unchanging values. Mark shortcuts with ponytail: comments.
